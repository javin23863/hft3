## Findings

- ES STATUS: LIVE. Phase 3 (entire S&P 500 options complex: SME, ES, EW, E1A-E5D weeklies, EW1-EW4, plus Micro MES/EX/X-weeklies/EX1-EX4) launched Sunday Feb 8, 2026 (first trade date Monday Feb 9, 2026), after a one-week delay from the original Sunday Feb 1 / trade-date Feb 2 schedule. CME's Feb 2, 2026 Globex Notice titled it 'Resting Order Elimination: Equity Index Options Variable Tick Expansion Phase 3 - This Week'; the Feb 9, 2026 notice carries no further mention (no second delay). As of 2026-06-12 it has been live ~4 months [3][10].
- Phase schedule: Phase 1 RTY (Russell 2000 options RTO, RTM, R1A-R5E weeklies) production launch Sunday Jan 11, 2026, trade date Monday Jan 12, 2026; Phase 2 NQ (Nasdaq-100 options NQ, QNE, Q*-weeklies + Micro MNQ, MQE, D*-weeklies, MQ1-MQ4) Sunday Jan 25, trade date Monday Jan 26, 2026; Phase 3 S&P Sunday Feb 8, trade date Feb 9, 2026. New Release (test env) launch for all three: Sunday Nov 9, 2025; CME Direct NR support Nov 13, 2025; no re-certification required for MDP 3.0-certified systems [1][10].
- OLD ES/SME grid (VTT code 15, Rule 358A01.C, pre-Feb-8-2026): premium <=10.00 index pts -> 0.05 tick ($2.50); >10.00 -> 0.25 ($12.50). Cabinet trades at 0.05 permitted; ClearPort clearing always 0.05 regardless of level [2][8].
- OLD NQ grid (VTT code 4, Rule 359A01.C): premium <=5.00 pts -> 0.05 ($1.00); >5.00 -> 0.25 ($5.00). OLD RTY grid (VTT code 1): <=5.00 -> 0.05 ($2.50); >5.00 -> 0.10 ($5.00) [2][8].
- NEW 4-level grid, VTT code 17 (applies to RTY AND all S&P 500 options incl. SME and Micros; display factor 0.01): |P| <= 5.00 -> 0.05; 5.00 < P <= 20.00 -> 0.10; 20.00 < P <= 100.00 -> 0.25; P > 100.00 -> 0.50. Raw Globex boundaries symmetric for negative UDS prices: +/-500, +/-2000, +/-10000 with raw ticks 5/10/25/50 [2].
- NEW 4-level grid, VTT code 18 (NQ + MNQ): |P| <= 5.00 -> 0.05; 5.00 < P <= 100.00 -> 0.25; 100.00 < P <= 500.00 -> 0.50; P > 500.00 -> 1.00. Raw boundaries +/-500, +/-10000, +/-50000; raw ticks 5/25/50/100 [2].
- Dollar-per-tick after change: ES ($50/pt): $2.50 / $5.00 / $12.50 / $25.00; MES ($5/pt): $0.25 / $0.50 / $1.25 / $2.50; NQ ($20/pt): $1 / $5 / $10 / $20; MNQ ($2/pt): $0.10 / $0.50 / $1.00 / $2.00; RTY ($50/pt): $2.50 / $5.00 / $12.50 / $25.00 [2][8].
- Net economic effect: ES coarsened 5.00-10.00 band (0.05->0.10) and >100 band (0.25->0.50), refined 10.00-20.00 (0.25->0.10); NQ purely coarsened above 100 pts (0.25->0.50) and above 500 pts (0.25->1.00) - ATM 30-45DTE NQ premiums (~300-700 pts in 2026) now tick at 0.50-1.00; RTY coarsened above 20 pts (0.10->0.25) and above 100 (->0.50). Deep-OTM wings <=5.00 unchanged at 0.05 everywhere [2][8].
- Exception: BX Box Spread type prices at 0.05 regardless of premium for all S&P 500 / Nasdaq-100 / Russell 2000 options; all other UDS/strategies follow expanded VTT pricing (added to wiki Oct 30, 2025) [1].
- GTC/GTD force-cancellation: customers asked to cancel all GTC/GTD after the close on the Friday prior to each launch; after 16:00 CT that Friday, CME Global Command Center (GCC) cancels/deletes ALL remaining GT orders in the affected options. Actual dates: Friday Jan 9, 2026 (RTY), Friday Jan 23, 2026 (NQ), Friday Feb 6, 2026 (S&P - originally Jan 30, moved with the delay) [1][3][4].

## Recommended actions

- Hard-code per-product tick ladders in the options lane: ES/MES/SME/RTY ladder {<=5.00: 0.05, <=20.00: 0.10, <=100.00: 0.25, >100: 0.50}; NQ/MNQ ladder {<=5.00: 0.05, <=100.00: 0.25, <=500.00: 0.50, >500: 1.00}; treat boundaries as crossable on tick-grid transitions and validate order prices against the ladder before submission (Globex rejects off-tick).
